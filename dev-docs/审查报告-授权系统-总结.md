## 四、过程 bug（全部当场修复）

1. auth-token 验签后漏 base64 解码直接 JSON.parse（bad_payload）
2. 挤下线未解除绑定关系（活跃数虚高、配额重复消耗）
3. 换绑月配额双计数器（evicted/unbind 分开可叠加刷）→ 统一口径
4. e2e 脚本自身指纹长度 50≠64、bash 中文参数/模板字符串多重坑 → e2e 固化为纯 mjs 文件
5. Turbopack HMR 过期产物导致阶段性误报（硬重启解决，教训：改码后硬重启再测）
