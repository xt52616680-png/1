## 过程中发现并修复的 bug（不带病前行）

1. **auth-token 验签后 payload 解析漏了 base64 解码**（JSON.parse 直接吃 base64url 字符串）→ 修正；调试脚本反向证明签名本身有效，快速定位
2. **挤下线未解除绑定关系**（userId 残留 → 活跃设备数虚高、重复驱逐死机器烧配额）→ 修复为解绑+作废双动作
3. **换绑月配额双计数器**（evicted 与 unbind 分开计数可叠加刷）→ 统一为单一配额口径
4. schema 漏 lastIp 字段导致 TS 报错 → 补齐
5. 测试脚本自身：指纹生成 50 字符不足 64、bash 中文参数 MSYS 转换坑 → e2e 固化为独立 mjs 脚本（scripts/e2e-auth.mjs，永久回归资产）
